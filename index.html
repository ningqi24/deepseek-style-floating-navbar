实时调节

拖下面的滑块，页头会立刻变。所有数值都是 CSS 变量，改完把这一段拷走就行。

设计令牌 改完直接在 CSS 里覆盖
80px

滚动后左右各内缩多少。相对容器计算，内容多也不会挤。

42px

滚动后的胶囊内容高度。调小 = 更「小而美」。

2px

滚动后的纵向内边距。

12px

磨砂玻璃的模糊半径。0 就是纯色背景。

0.45

玻璃底色不透明度（浅色主题）。


    

  


  

    

      
怎么用

      
两个文件，零依赖，不需要构建。把结构放进去、把两个文件引进来就完事了。


      
    
        
  1. 01
    放结构
    类名固定三层：.gnav > .gnav__bar > .gnav__inner。中间层是胶囊本体，所以它外面的区域不会被挡住点击。
    2. 
        
  2. 02
    引文件
    <link rel="stylesheet" href="glass-navbar.css"> 加 <script src="glass-navbar.js"></script>。脚本会自动初始化页面上所有 .gnav。
    3. 
        
  3. 03
    改数值
    用 CSS 变量覆盖（见 参数表）。想调多细、多宽，只改 CSS，不用碰 JS。
    4. 
      


      
<header class="gnav">
  <div class="gnav__bar">
    <div class="gnav__inner">
      <!-- 你的 logo / 导航 / 按钮 -->
    </div>
  </div>
</header>

<link rel="stylesheet" href="glass-navbar.css">
<script src="glass-navbar.js"></script>

    

  


  

    

      
为什么用弹簧，而不是 CSS transition

      

        width、padding、height 走 CSS 过渡是「匀速收束 + 固定时长」，
        看着很机械 —— 你滚到一半往回滚，它会硬生生掉头。
      


      
a = (-k * (x - target) - c * v) / m;
v += a * dt;
x += v * dt;


      

        弹簧会带着当前速度继续走，所以连续上下滚动时手感是连续的。
        默认 k = 180、c = 28、m = 1；
        临界阻尼是 2√(k·m) = 2√180 ≈ 26.8，取 28 刚好比它大一点：
        不回弹，但收束是平滑的。
      

      

        工程细节也处理了：单步时长夹在 1/30 秒内（切回标签页时不会积分炸掉）、
        位移与速度都收敛就吸附到目标并停掉 rAF（不空转）、
        窗口缩放时直接落值（不会看到一段无意义的收放动画）、
        prefers-reduced-motion 下完全不做动画。
      

    

  


  

    

      
参数表

      
全部在 glass-navbar.css 里以 CSS 变量定义，在 .gnav 上覆盖即可。


      

        

          
变量默认值说明

          
            
--gnav-inset80px滚动后左右各内缩多少。容器窄于 --gnav-inset-min 时自动不内缩。

            
--gnav-inset-min720内缩的最小容器宽度（无单位数字）。

            
--gnav-top / -on8px / 5px容器顶部留白，未滚动 / 滚动后。

            
--gnav-pad-y / -on4px / 2px胶囊纵向内边距。

            
--gnav-inner-h / -on48px / 42px胶囊内容高度。

            
--gnav-pad-l-on / -r-on18px / 12px滚动后内容左右内缩，避免贴到圆角。

            
--gnav-max-width1280px容器最大宽度。

            
--gnav-side-gap32px容器距视口左右边缘的留白。

            
--gnav-radius100px胶囊圆角。

            
--gnav-blur12px磨砂玻璃模糊半径。

            
--gnav-saturate170%磨砂玻璃饱和度增强。

            
--gnav-surfacehsla(0,0%,100%,.45)玻璃底色。

            
--gnav-borderrgba(0,0,0,.1)玻璃描边。

            
--gnav-shadow0 2px 12px rgba(21,36,67,.07)胶囊投影。

            
--gnav-glass-duration.3s玻璃淡入时长（外观走 CSS 过渡，尺寸走弹簧）。

          
        

      


      
物理参数用 data 属性覆盖：

      

        

          
属性默认值说明

          
            
data-gnav-threshold80触发收窄的滚动距离（px）。

            
data-gnav-stiffness180弹簧劲度系数 k，越大越快。

            
data-gnav-damping28阻尼系数 c，越小越容易回弹。

            
data-gnav-mass1质量 m。

          
        

      


      
也可以手动实例化：

      
const nav = new GlassNavbar('#gnav', { threshold: 120, stiffness: 220, damping: 30 });
nav.settle();    // 不做动画，直接落到当前状态
nav.destroy();   // 移除实例并清掉内联样式

    

  


  

    

      
兼容性与无障碍

      

        Chrome / Edge 88+、Safari 15.4+、Firefox 103+。
        backdrop-filter 不支持时自动退化为纯色背景（@supports 兜底），
        功能不受影响。深色模式跟随系统，也可以用手动指定
        [data-theme="dark"] 或 .gnav--dark / .gnav--light。
        开启「减弱动态效果」后尺寸变化不再有动画，直接落值。
